## 安装

### 1. 克隆或下载项目

```bash
cd llm_client
```

### 2. 安装依赖

根据你想使用的界面，安装对应依赖：

```bash
# 基础依赖（CLI 模式必需）
pip install ollama requests

# TUI 模式需要
pip install textual

# GUI 模式需要
pip install PyQt6

# 安装全部依赖
pip install -r requirements.txt
```

### 3. 准备后端

**Ollama**：
```bash
# 安装并启动 Ollama
ollama serve
# 拉取模型
ollama pull llama3.1
ollama pull llava  # 视觉模型
```

**llama.cpp**：
```bash
# 编译并启动 server
./server -m model.gguf --port 8080
```
